## Key Features

This application was meticulously crafted with a focus on both aesthetics and functionality.

#### ✨ A Stunning, Modern UI
*   **Futuristic Dark UI:** A gorgeous, professional dark theme with glassmorphism ("frosted glass") panels.
*   **Dynamic "Living" Background:** An advanced, animated particle constellation background that is subtle, clean, and beautiful.
*   **Polished Micro-interactions:** Every button, hover effect, and transition has been refined to feel smooth, responsive, and satisfying.
*   **Professional Splash Screen:** An elegant, animated splash screen provides a premium loading experience when you launch the application.

#### ⚙️ Powerful NBT Editing
*   **Full NBT Read/Write Support:** Parse and write all standard NBT tag types with a robust and reliable engine.
*   **Live Editing:** Directly edit tag values in the JSON inspector and see your changes reflected instantly in the live NBT tree with the "Apply Changes" button.
*   **State Preservation:** The application intelligently remembers your view—which folders are open and which tag is selected—even after applying changes, so you never lose your place.
*   **Direct File Overwriting:** As a true desktop application, "Save NBT" **directly overwrites your file**, providing a seamless and powerful editing workflow.

#### 🗂️ Unmatched Workflow
*   **Hierarchical Folder Explorer:** Open entire folders (like Minecraft saves) and navigate their complete nested directory structure, just like the original NBTExplorer.
*   **Seamless Context Switching:** Effortlessly switch from browsing a folder structure to diving deep into a single file's NBT tree, and navigate back with a single click.
*   **Authentic Icons:** Familiar and intuitive icons for folders and NBT files ("chests") make navigation a breeze.
*   **100% Offline Capable:** The final built executable is completely self-contained and requires no internet connection to run at full functionality.

## Future Plans & Roadmap

While this edition is definitive, the journey of improvement never ends. Future plans include:

*   [ ] **Advanced Search:** Implement a powerful search feature to find tags by name or value within a file.
*   [ ] **GUI-based Editors:** Create specialized editors for certain tag types (e.g., a simple text field for strings, a number input for integers) as an alternative to raw JSON editing.
*   [ ] **Multi-Platform Builds:** Officially configure builds for macOS (`.dmg`) and Linux (`.AppImage`).
*   [ ] **Plugin System:** Explore the possibility of a plugin system to handle custom NBT data from mods.

See the [open issues](https://github.com/HamaSisko/NBTExplorer-Definitive/issues) for a full list of proposed features (and known issues).
